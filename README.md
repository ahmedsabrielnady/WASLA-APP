# WASLA | وصلة

منصة خدمات محلية تبدأ من شبين القناطر، القليوبية.

## حالة المشروع

المستودع يحتوي حاليًا على نموذج HTML أولي. لا ينبغي اعتبار جميع القطاعات أو وظائف الحجز والطلبات أو لوحة المؤسس جاهزة للإنتاج.

- الفرع الرئيسي: `main` (لم يتم تغييره في مرحلة التدقيق).
- فرع التأسيس والمراجعة: `project/phase-0-discovery`.
- تم تنفيذ فحص ساكن لملفات الواجهة.
- تم فحص مشروع Supabase المتصل فعليًا، ومخططه وسياساته ووظائفه وتنبيهات الأمان والأداء. ظهرت migrations إضافية أثناء المراجعة، وتم تحديث التقرير بالأثر الحالي ومصدر عدم اليقين.
- تم تطبيق تعديل محدود على صلاحيات/تحقق الدعوات على مشروع Supabase المتصل، واختباره باختبار SQL معزول.
- لم يتم تنفيذ اختبار تشغيل كامل للموقع أو اختبار متصفح أو اختبار end-to-end.
- يوجد اختلاف بين Project URL في ملفات `main` ومشروع Supabase المتصل؛ لا تغيّر الإعداد قبل حسم قاعدة الإنتاج الصحيحة.

## مبدأ التطوير

كل تغيير لاحق يأتي عبر فرع مستقل ومراجعة واختبارات موثقة. لا تُرفع أسرار خادمية إلى الواجهة أو GitHub، ولا تدخل بيانات مرضى حقيقية قبل مراجعة الخصوصية والأمان والنسخ الاحتياطي والامتثال القانوني. يجب اختبار RLS ودوال RPC بهويات وأدوار متعددة؛ مجرد تفعيل RLS لا يثبت سلامة السياسات.

## تنبيه

Free tiers مخصصة للتطوير والتجارب ضمن حدودها؛ لا تمثل ضمانًا لاستمرارية منصة تجارية أو طبية. لا توجد طريقة هندسية تضمن صفر أخطاء، لكن يمكن خفض المخاطر عبر الاختبارات والنسخ الاحتياطي ومراقبة التشغيل وإجراءات الاستجابة.
