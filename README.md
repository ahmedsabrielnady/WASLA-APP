# WASLA | وصلة

منصة خدمات محلية تبدأ من شبين القناطر، القليوبية.

## حالة المشروع

المستودع يحتوي حاليًا على نموذج HTML أولي. لا ينبغي اعتبار جميع القطاعات أو وظائف الحجز والطلبات أو لوحة المؤسس جاهزة للإنتاج.

- الفرع الرئيسي الحالي: main
- فرع التأسيس والمراجعة: project/phase-0-discovery
- المراجعة الحالية: فحص ساكن للملفات المنشورة
- لم يتم تنفيذ اختبار تشغيل كامل أو اختبار تكامل مباشر مع قاعدة Supabase في هذه المرحلة.

## مبدأ التطوير

نحتفظ بفرع main دون تغيير أثناء مرحلة التأسيس. كل تغيير لاحق يجب أن يأتي عبر فرع مستقل ومراجعة واختبارات موثقة. لا تُرفع أسرار خادمية إلى الواجهة أو GitHub، ولا تدخل بيانات مرضى حقيقية قبل مراجعة الخصوصية والأمان والنسخ الاحتياطي والامتثال القانوني.

## تنبيه

Free tiers مخصصة للتطوير والتجارب ضمن حدودها؛ لا تمثل ضمانًا لاستمرارية منصة تجارية أو طبية. لا توجد طريقة هندسية تضمن صفر أخطاء، لكن يمكن خفض المخاطر عبر الاختبارات والنسخ الاحتياطي ومراقبة التشغيل وإجراءات الاستجابة.
