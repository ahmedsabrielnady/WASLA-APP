## نتائج مراجعة الأمان الحالية

- Supabase Security Advisor: 20 دالة SECURITY DEFINER متاحة لدور authenticated. تمت مراجعة تعريفات الدوال العشرين؛ كثير منها يفرض تحققًا داخليًا من هوية المستخدم أو دوره أو ملكية السجل. أضيفت دالة staff_set_order_status_v2 بعد اكتشاف أن لوحة التشغيل كانت تستدعي RPC قديمًا مسحوب الصلاحية؛ تم اختبار سماح حساب staff ورفض حساب customer داخل معاملات متراجعة.
- `admin_reset_user_password` دالة حساسة تغيّر كلمة مرور مستخدم؛ تعتمد على فحص دور admin داخل الدالة. يجب اختبار رفضها لحساب عميل ومقدم خدمة قبل الإطلاق.
- Leaked Password Protection معطلة في Supabase Auth وتحتاج تفعيلًا من إعدادات Auth.
- جدول `order_status_transitions` عليه RLS بلا سياسات؛ هذا مقصود حاليًا للوصول المقيد عبر مسارات قاعدة البيانات، ولا تُضف سياسة عامة لمعالجة التنبيه.
- ظهرت ملاحظات أداء غير حرجة: فهارس غير مستخدمة حاليًا بسبب قلة البيانات، وسياسات RLS permissive متداخلة على بعض الجداول. لا تحذف فهارس أو تغيّر سياسات دون تحليل أثر.
- MFA لحساب الإدارة لم يتم التحقق منه.
